Snap Options + Numeric Input + DXF I/O
每刃吃刀 (Fz)-- mm
表面速度 (Vc)-- m/min
材料移除率-- cm³/m
主軸轉速-- RPM
Near = 線段投影最近點（做幾何對齊很有用）
Center = 封閉圖形的中心（用 bbox 中心，避免 centroid 偏心）
    小提醒：你要「幾何更精準 / 對 CAM 更乾淨」，第一刀就是把吸附拆開。以前那種一鍋端的 snap 只會把你逼瘋。現在你可以只開 End+Near 或只開 Grid，避免偷吸到 midpoint 亂跑。
    數值輸入
    在畫圖中輸入數值，按「套用」或 Enter。
